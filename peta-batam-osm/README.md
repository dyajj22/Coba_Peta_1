# Peta kebisingan kawasan industri Batam

Peta interaktif: sebaran kebisingan dari 26 kawasan industri di Pulau Batam, dengan suara yang berubah menurut jarak.

- Ketuk atau seret titik hijau untuk berpindah, lalu dengarkan.
- Cari kawasan lewat kotak pencarian.

Catatan: tingkat bising adalah model ilustratif dari luas lahan, bukan hasil pengukuran.
Peta dasar © OpenStreetMap contributors.

## Cara menayangkan di GitHub Pages
1. Buat repositori baru, lalu unggah `index.html` ke folder utama (root).
2. Buka Settings, lalu Pages.
3. Pada Source pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit. Alamatnya `https://USERNAME.github.io/NAMA-REPO/`.
